# Projeto E-learning — Segurança do Paciente na APS

## Sobre o projeto

Curso de capacitação voltado a profissionais da Atenção Primária à Saúde (APS), desenvolvido como parte do trabalho de mestrado da cliente Lucimara.

O conteúdo tem como objetivo qualificar profissionais para reconhecer riscos assistenciais, aplicar práticas seguras no cuidado e fortalecer a cultura de segurança do paciente.

## Informações do projeto

| Informação | Detalhe |
|---|---|
| Cliente | Lucimara |
| Tipo | Curso e-learning |

| Público-alvo | Profissionais da Atenção Primária à Saúde, especialmente profissionais em início de atuação |
| Ferramenta de autoria | Adobe Captivate Classic |

## Estrutura do repositório

O repositório contém a exportação HTML5 do curso e seus recursos de execução:

- `index.html`: ponto de entrada do curso exportado pelo Captivate;
- `assets/`: arquivos de suporte utilizados pelo conteúdo, incluindo CSS, JavaScript, imagens e ícones;
- `dr/`: arquivos JSON de recursos utilizados pela exportação;
- `ar/`: recurso de áudio;
- `certif.html`: página HTML do certificado de conclusão;
- `goodbye.html`: página de encerramento;
- `project.txt`: arquivo de dados/estrutura gerado na exportação do Captivate;
- `LICENSE`: licença presente no repositório.

Consulte [`docs/README.md`](docs/README.md) para a documentação do projeto.

## Manutenção

O arquivo-fonte editável do Adobe Captivate (`.cptx`) está com a cliente e não faz parte deste repositório. Portanto, alterações estruturais no conteúdo do curso devem ser realizadas a partir do arquivo-fonte disponibilizado pela cliente e, após a exportação, os arquivos publicados devem ser atualizados de forma compatível com a estrutura existente.

Este repositório documenta os arquivos mantidos pela equipe da Pegasus. Não há, nesta documentação, identificação ou endereço confirmado de outro repositório mantido pela cliente.

## Observações

- O curso utiliza recursos próprios do Adobe Captivate, como navegação, mapa do curso e quizzes.
- Não foram identificadas integrações externas com LMS, SCORM ou xAPI no escopo informado.
- A documentação detalhada da organização do curso está em [`docs/curso/estrutura.md`](docs/curso/estrutura.md).
