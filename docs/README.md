## Orientações

A documentação complementa os arquivos exportados do Adobe Captivate. Ela não substitui o conteúdo do curso, o arquivo-fonte editável ou os recursos de autoria da ferramenta.

O arquivo-fonte original (`.cptx`) está com a cliente. Para alterações no conteúdo ou na organização das telas, é necessário obter esse arquivo antes de realizar uma nova edição e exportação.

Registre neste diretório apenas informações confirmadas e relevantes para a compreensão e continuidade do projeto.
